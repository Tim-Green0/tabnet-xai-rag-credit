# 제 8 장. 결론 및 시사점

## 8.1 연구 요약

본 연구는 정형 데이터 특화 딥러닝 모델인 TabNet의 인스턴스 어텐션과 트리 부스팅 모델인 XGBoost의 SHAP local 기여도를 *동의 기반(agreement-aware)* 으로 융합한 신규 컨텍스트를 설계하고, 이를 거대언어모델(LLM)의 검색 증강 생성(RAG) 파이프라인에 입력하여 신용평가 결과의 자연어 설명 리포트를 자동 생성하는 시스템을 제안하였다.

본 연구의 시스템은 4단계 파이프라인(예측 → 해석 → 융합 컨텍스트 → 자연어 생성)으로 구성되며, 룰 기반 충실성·환각률, mDeBERTa-NLI 기반 함의도, 교차 LLM G-Eval, 3-페르소나 LLM 대리 평가의 4-tier 평가 프레임워크와 4/5 규칙 기반의 공정성 평가를 통해 시스템 출력의 사실성·충실성·이해관계자별 적합성·공정성을 정량 측정하였다.

본 연구는 Kaggle Home Credit Default Risk(307,511명, 214 변수)와 UCI German Credit(1,000명, 63 변수) 두 개의 공개 신용평가 데이터셋을 동일 파이프라인에 적용하여, 본 연구 메커니즘의 일반화 가능성을 검증하였다.

주요 결과는 다음과 같다.

1. **모델 성능**: XGBoost가 두 데이터셋 모두에서 5-fold CV AUROC 약 0.76~0.77 수준의 일관된 예측 성능을 보였다. TabNet은 0.7543(Home), 0.7499(German)으로 XGBoost와 0.5%p 이내의 작은 차이로 보조 모델과 어텐션 추출용으로 적합함을 입증하였다.

2. **SHAP × 어텐션 일관성**: 두 데이터셋에서 Spearman 상관계수가 거의 동일하게 약한 양의 상관(ρ = 0.117 vs 0.114)으로 관찰되어, *부분 일관 + 부분 상보* 의 패턴이 신용평가 도메인의 일반 패턴임을 정량적으로 확인하였다.

3. **fusion의 NLI 사실성 1위**: 두 데이터셋 모두에서 *no_shap < generic_rag < shaponly < fusion* 의 NLI Entailment 단조 증가 패턴이 일관되게 관찰되었다. fusion은 Home Credit에서 0.625, UCI German Credit에서 0.711의 entailment를 보이며 4-mode 중 1위를 차지하였다.

4. **환각 차단의 분리**: 4-mode 모두에서 환각률 0%가 달성되었으며, 이는 hard constraint만으로 환각 차단이 충분조건임을 의미한다. fusion의 차별성은 *환각 차단이 아닌 fact-grounded 충실성과 값 정확 인용* 에 있음을 정량적으로 분리·입증하였다.

5. **공정성 보정**: Reweighing이 보호 속성(GENDER, AGE) × 데이터셋(baseline, aux)의 4가지 조합 모두에서 4/5 규칙을 통과하면서 AUROC 손실은 0.004 이내로 유지되었다. Fairlearn DP는 큰 AUROC 손실을, EO는 4/5 규칙 보장 부재의 본질적 한계를 보였다.

6. **응용 시나리오 trade-off**: Persona 평가에서 fusion이 Credit Expert·Regulator의 trustworthiness 1위(4.81, 4.75)를 차지하였으나, Customer clarity는 2.67로 *최하위* 였다. 반면 generic_rag는 Customer clarity 1위(4.93)를 차지하여, *audit/regulation = fusion / customer-facing = generic_rag* 의 mode 선택 가이드라인이 정량 입증되었다.

7. **데이터 복잡도 차원**: G-Eval Completeness에서 Home Credit은 fusion 1위(4.82), UCI German Credit은 generic_rag 1위(4.58)로 정반대 결과가 관찰되어, *데이터 복잡도가 fusion 우월성의 결정적 변수* 임이 확인되었다.

## 8.2 본 연구의 학술적 기여

본 연구는 다음과 같은 다섯 가지 학술적 기여를 제시한다.

### 8.2.1 Agreement-aware Fusion Context의 신규 설계 (C1)

본 연구의 가장 중요한 기여는 *동의 기반 융합 컨텍스트* 의 신규 설계이다. 기존 연구에서는 SHAP과 어텐션을 각각 단독으로 활용하거나 단순 결합한 사례만 존재하였으나, 본 연구는 두 해석 모델의 *동의 여부* 자체를 LLM 컨텍스트의 명시적 신호로 활용하는 첫 사례이다. 동의 그룹·SHAP 단독·어텐션 단독의 3-그룹 분류와 JSON 구조는 다른 정형 데이터 도메인에도 일반화 가능한 *표준 컨텍스트 형식* 으로 활용될 수 있다.

### 8.2.2 4-tier 다중 평가 프레임워크 구축 (C2)

본 연구가 구축한 룰·NLI·G-Eval·Persona의 4-tier 평가 체계는 LLM 기반 자연어 설명의 사실성·충실성·이해관계자 적합성을 단일 지표로는 잡히지 않는 다차원에서 측정한다. 특히 cross-judge G-Eval과 LLM-proxy persona 평가는 self-bias와 IRB 부담의 두 가지 한계를 제도적으로 완화하는 절충 방안으로 학술적 가치를 갖는다.

### 8.2.3 환각 차단 vs fact-grounding의 분리 입증 (C3)

본 연구는 4-mode 비교를 통해 *환각률 0%는 hard constraint만으로 충분* 하지만 *fact-grounded 충실성은 fusion이 필요* 함을 정량적으로 분리하였다. 이는 본 연구의 학술적 메시지를 *trivial한 환각 차단 주장* 에서 *fact-grounded 차별성* 으로 정교화하는 핵심 근거이다.

### 8.2.4 일반화 검증 (C4)

본 연구의 메커니즘이 Home Credit과 UCI German Credit 두 데이터셋에서 SHAP × 어텐션 ρ ≈ 0.11과 NLI 단조 증가 패턴을 일관되게 보임을 입증하여, 본 연구의 발견이 단일 데이터셋 특수 패턴이 아닌 신용평가 도메인의 일반 패턴임을 정량 확인하였다. 동시에 G-Eval Completeness의 데이터셋별 차이를 통해 *데이터 복잡도가 fusion 우월성의 결정적 변수* 임을 honest reporting으로 추가 발견하였다.

### 8.2.5 공정성 보정의 무손실 적용 (C5)

본 연구의 Reweighing 적용 결과는 신용평가 도메인에서 *공정성 보정이 모델 성능 손실 없이 가능* 함을 입증한다. 4가지 보호 속성 × 데이터셋 조합 모두에서 4/5 규칙 통과를 AUROC 손실 0.004 이내에서 달성하였으며, 특히 aux 데이터셋에서는 AUROC가 오히려 향상되는 결과를 얻었다. 이는 산업 신용평가 시스템의 공정성 규제 준수에 직접적인 정량 근거를 제공한다.

## 8.3 산업적 시사점

본 연구의 결과는 신용평가 산업의 자연어 설명 시스템 도입에 다음과 같은 시사점을 제공한다.

첫째, **응용 시나리오별 mode 선택**이 가능하다. 본 연구의 정량 평가는 audit·내부 감사·규제 준수 환경에서는 fusion 모드가, 고객 응대 환경에서는 generic_rag 모드가 적합함을 보여준다. 이를 통해 단일 자연어 설명 시스템이 응용 시나리오에 맞는 모드를 선택적으로 활용하는 *adaptive* 운영이 가능하다.

둘째, **hard constraint 정책의 산업 적용 가능성**이 직접 확인되었다. 5가지 단순 자연어 제약문만으로 환각이 안정적으로 차단되며, 이는 LLM 기반 신용평가 자동화 시스템의 *법무·규제 검토 통과 가능성* 을 높이는 실용적 근거이다.

셋째, **공정성 보정의 비즈니스 손실 최소화**가 입증되었다. Reweighing은 학습 데이터의 가중치만 재계산하므로 기존 모델 인프라의 변경 없이 적용 가능하며, AUROC 손실이 0.4%p 이내로 비즈니스 영향을 최소화한다.

넷째, **두 LLM(Anthropic Claude, Google Gemini)의 일관성**이 입증되어, 본 연구의 결과가 단일 LLM 의존이 아님을 확인하였다. 산업 운영에서는 LLM 모델의 라이선스·비용·응답 시간 측면에서 두 모델 중 적절한 선택이 가능하다.

## 8.4 마무리

본 연구는 정형 데이터 신용평가의 예측 정확성, 모델 해석 정보의 통합, LLM 자연어 설명의 fact-grounding, 응용 시나리오별 trade-off, 그리고 공정성 규제 준수의 다섯 가지 목표를 동시에 추구하는 통합 시스템을 제안하였다. 본 연구의 *동의 기반 융합 컨텍스트* 와 *4-tier 평가 프레임워크* 는 신용평가 도메인의 학술 연구와 산업 적용 양 측면에서 활용 가능한 *재현 가능한 방법론* 으로 GitHub 공개 저장소(`Tim-Green0/tabnet-xai-rag-credit`)에 모든 코드와 결과를 공개하였다.

본 연구가 명시적으로 보고한 한계 — 표본 30 건 수준의 평가, LLM-proxy persona의 IRB 부재, hard constraint 의존성, Customer clarity 약점, 한국어 humanize 매핑 의존 — 는 향후 연구에서 정식 IRB 인간 평가, 추가 데이터셋 검증, 3-way ablation 분석, hybrid prompt 설계, 그리고 자동 한국어 변환 framework 개발을 통해 단계적으로 보완될 수 있다.

본 연구가 제시한 *fusion 메커니즘은 NLI 사실성에서 일관 1위이지만 데이터 복잡도와 평가 차원에 따라 mode 선택 trade-off가 존재함* 의 honest reporting은 단순 우월성 주장보다 학술적 가치가 높으며, 본 연구의 산업 적용 시점에 운영자가 응용 시나리오에 맞는 모드를 선택할 수 있는 *정량 근거* 로 작용한다. 본 연구가 신용평가 도메인의 *설명 가능한 AI* 와 *책임 있는 AI* 두 측면에 모두 의미 있는 기여를 하였기를 기대한다.
