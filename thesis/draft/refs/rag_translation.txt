                               Abstract

  In specialized domain translation, the accurate translation of domain-

specific terminology significantly affects overall translation quality.

However, traditional machine translation models and monolithic systems

based on a single LLM struggle to achieve high performance on specialized

terminology translation in low-resource domains due to insufficient pre-

trained knowledge when parallel corpora are limited. This issue is

especially severe in the Korean low-resource domain, where the lack of

parallel corpora makes additional model training and evaluation difficult.

  To address this problem, this study designed a multi-agent translation

system for English-to-Korean translation. It consists of draft translation,

domain   terminology   extraction,   feedback   generation,   and   revised

translation. A synthetic parallel corpus was generated by back-translation

of Korean monolingual data and used as a RAG knowledge base. By using

terminology translation feedback generated from RAG retrieved context,

terminology translation accuracy was improved significantly compared to

the draft translation without RAG. Experiments conducted on the chess

domain, one of the Korean low-resource domains, showed that the proposed
system achieved a terminology translation accuracy of 85.2% with the GPT-

5 model, outperforming commercial translation systems including Google

Translate(78.1%), DeepL(49.2%), and Papago(35.5%). These results suggest

that RAG and a multi-agent system can be effective for Korean low-resource

domain translation.

단일 LLM으로 구성된 모놀리식 시스템의 경우 병렬 말뭉치가 부족한 저자원

도메인에서 사전 학습된 지식이 부족한 문제로 전문 용어 번역에서 높은 성능

을 내기 어렵다. 특히 한국어 저자원 도메인의 경우 병렬 말뭉치가 부족하기

때문에 추가적인 모델 학습 및 평가 또한 어려운 환경이다.

 본 연구에서는 이러한 문제를 해결하기 위해서 영한 번역을 대상으로 초벌

번역, 도메인 용어 추출, 피드백 생성, 수정 번역의 4단계로 구성된 다중 에

이전트 기반 번역 시스템을 설계하였다. 한국어 monolingual 데이터를 역번역

하여 합성 병렬 말뭉치를 구축하고 이를 RAG 지식 베이스로 활용하였으며,

RAG 기반 컨텍스트로 생성된 전문 용어 번역 피드백을 사용함으로써 RAG를 사

용하지 않은 초벌 번역에 비해 전문 용어 번역 정확도가 유의미하게 향상되는

것을 확인하였다. 한국어 저자원 도메인 중 하나인 체스 도메인을 대상으로

실험한 결과, 제안된 시스템은 GPT-5 모델 기준 전문 용어 번역 정확도 85.2%

를 달성하였으며 이는 상용 번역기인 Google Translate(78.1%), DeepL(49.2%),

Papago(35.5%)보다 우수한 성능을 보였다. 이는 RAG와 다중 에이전트 기반의
번역 시스템이 한국어 저자원 도메인 번역에서 효과적일 수 있다는 가능성을

제시하였다.
                     제 1 장 서론

제 1 절 연구 배경

 전문 분야에서의 번역은 도메인 고유의 전문 용어를 정확하게 처리하는 것

이 전체 번역 품질에 큰 영향을 미친다. 의료, 기술, 법률과 같은 도메인에서

는 용어 하나의 오류가 의미 왜곡으로 이어질 수 있기 때문에 전문 용어의 정

확한 번역은 번역 평가의 핵심적인 기준이 된다. 그러나 기존의 전통적인 기

계   번역   모델이나   단일   LLM(Large   Language   Model)   기반의   모놀리식

(monolithic) 시스템의 경우 전문 용어에 대해서 번역 정확도가 떨어지는 문

제점이   있다. 이는 병렬      말뭉치(corpus)가 부족한            저자원   도메인(low-

resource)에서 더욱 두드러지며, 모델이 사전 지식을 충분히 학습하기 어렵기

때문에 전문 용어를 올바르게 번역하지 못하는 현상이 발생한다.

 LLM 분야의 발전으로 LLM의 한계를 극복하기 위한 다양한 연구들이 진행되

는 한편 다중 에이전트 시스템과 RAG와 같은 기법들이 주목받고 다양한 분야

에서 높은 잠재력을 보여주고 있다. 다중 에이전트 시스템은 각자의 역할을

가진 여러 개의 전문적인 에이전트들이 협력하여 복잡한 문제를 해결하며 특

정 작업에서 단일 LLM 기반 모놀리식 시스템보다 높은 성능을 달성하고 있다.

RAG의 경우 LLM이 외부 데이터베이스에서 필요한 정보를 검색하고 검색된 정

보를 기반으로 답변을 생성하는 기법이다. 학습된 지식만으로 답변하는 LLM의




                             1
단점을 보완하며 별도의 파인 튜닝(Fine-Tuning)이 필요 없다는 장점이 있다.

저자원 도메인에서는 파인 튜닝을 하기 위한 충분한 데이터셋이 없는 경우가

많기 때문에 특히 유용한 접근 방법이 될 수 있다.

 RAG와 다중 에이전트 시스템은 기존의 LLM의 한계를 뛰어넘을 수 있는 새로

운 기회를 제공한다. 그러나 RAG와 다중 에이전트 시스템을 사용한 번역에 대

한 연구는 아직 초기 단계이며[1] 한국어 저자원 도메인에 적용하여 번역 성

능을 정량적으로 평가한 연구는 부족한 상황이다. 따라서 본 연구에서는 초벌

번역, 도메인 용어 추출, 피드백 생성, 수정 번역의 단계로 구성된 다중 에이

전트 기반 번역 시스템을 제안하며 한국어 저자원 도메인의 번역 분야에서의

가능성을 검증한다.




제 2 절 연구 목적

 본 논문에서의 연구 목표는 다음과 같다.

 첫째, 한국어 저자원 도메인 영한 번역의 전문 용어 번역 정확도를 높이기

위해서 RAG 기반 다중 에이전트 번역 시스템을 설계한다. 최근 다양한 분야에

서 다중 에이전트를 사용하여 단일 LLM 기반의 시스템의 한계를 극복하고 복

잡한 작업을 수행하기 위한 연구들이 이루어지고 있다. 그러나 저자원 도메인

번역 문제에 적용한 연구는 부족한 상황이다. 따라서 다중 에이전트 기반 설




                       2
계를 한국어 저자원 도메인 번역에 적용하여 실제로 전문 용어 중심의 번역

품질을 향상시킬 수 있는지에 대한 가능성을 검증한다.

 둘째, RAG 지식 없이 LLM이 생성한 번역을 RAG 기반의 피드백을 통해 개선

하였을 때 번역 성능을 향상시킬 수 있는지 확인한다. ChatGPT와 같은 LLM은

대용량 말뭉치를 기반으로 학습되는데 저자원 도메인의 경우 학습 데이터가

충분하지 않아 전문 용어에 대해서 지식이 부족한 특징이 있다. 따라서 RAG

지식 없이 번역을 수행하였을 때 전문 용어를 잘못 번역하는 문제가 발생한

다. RAG를 통해 검색된 도메인 지식을 바탕으로 번역 피드백을 생성하고 이를

적용하여 번역을 개선하도록 하였을 때 번역 품질이 향상되는지를 정량적으로

검증한다.

 셋째, RAG 기반 다중 에이전트 번역 시스템과 상용 번역 시스템 간의 성능

에 대해서 비교하고 한국어 저자원 도메인의 번역에서 다중 에이전트 번역 시

스템이 상용 번역기보다 높은 품질의 번역을 생성할 수 있는지 자동평가 지표

로 평가하는 것이다. 한국어 저자원 도메인의 경우 병렬 말뭉치 부족으로 상

용 번역기에서도 전문 용어 번역에서 한계를 드러내는 경우가 많다. 대표적인

상용 번역기인 Google Translate, DeepL, Papago를 비교 대상으로 선정하여

전문 용어 번역 정확도 지표를 활용해 번역 품질을 정량적으로 분석한다.

 본 논문의 구성은 다음과 같다. 제 1 장 서론에서는 연구의 배경과 목적에

기반의 번역 시스템이 가지는 의미와 향후 연구 방향을 제시한다.

                  제 2 장 이론적 배경

제 1 절 기계 번역

 기계 번역은 NLP(Natural Language Processing) 분야 중 하나로 컴퓨터를

사용하여 자연어를 번역하는 기술로 규칙 기반의 RBMT(Rule Based Machine

Translation)와 통계 기반의 SMT(Statistical Machine Translation)을 거쳐

신경망 기반의 NMT(Neural Machine Translation)으로 발전해 왔다. 초기의 규

칙 기반 번역은 사람이 직접 만든 규칙과 언어 지식에 의존하였고 언어의 본

질적인 복잡성 때문에 한계가 존재하였다. 이후 통계 기반의 SMT가 등장하여

대규모의 병렬 말뭉치에서 번역 규칙들을 직접 학습하도록 하였다. 하지만 통

계적인 모델은 문맥을 완벽하게 이해하지 못하였기 때문에 번역 품질이 만족

스럽지 못하였다. 이후 딥러닝의 발전으로 신경망 기반의 NMT가 등장하였으며

기존의 SMT보다 좋은 성능을 보여주며 SMT를 대체하였다[2].

 NMT는 병렬 말뭉치를 end-to-end로 학습하여 번역을 수행하며 인간의 개입

없이 자동으로 번역 규칙을 학습한다. SMT에 비해 문맥과 단어 사이의 복잡한

관계도 학습하며 자연스러운 번역을 할 수 있게 되었다. 그러나 학습에 사용

되는 데이터에 대한 의존성이 높아 훈련 데이터가 부족한 저자원 언어나 도메

인에서 성능 저하를 보이는 한계를 지닌다. 또한 새로운 도메인에 특화된 번




                              5
역을 하기 위해서는 해당 분야의 병렬 데이터를 수집하고 파인 튜닝을 하여야

하는데 이는 시간과 비용이 많이 소요되는 한계점이 있다[3].

 최근     GPT     모델과   같은     LLM이    등장하면서 고자원          언어(high-resource

language) 번역에서 우수한 성능을 보이며 일부 언어쌍에서는 상용 번역기를

능가하는 SOTA(state-of-the-art) 수준의 품질을 달성할 수 있는 것으로 나타

났다[4]. 그러나 이러한 성능 향상에도 불구하고 LLM 또한 NMT와 유사한 한계

점을 공유하고 있다. LLM은 방대한 양의 말뭉치를 사전 학습하여 폭넓은 지식

과 더 나은 문맥 이해 능력을 가졌지만 여전히 훈련 데이터에 포함되지 않은

저자원 언어 혹은 저자원 도메인에 대해서 성능 한계를 보인다.

  최근에는 LLM 기반의 다중 에이전트 시스템을 기계 번역에 적용하려는 연

구들이 이루어지고 있으며 [5]에서 제안된 TransAgents 프레임워크는 LLM 기

반의 다중 에이전트 시스템이 실제 복잡한 번역 작업에서 유의미한 성능 향상

을 가져올 수 있음을 보여주는 중요한 사례이다. 해당 연구에서는 문학 텍스

트 번역이라는 기존의 시스템들이 처리하기 어려운 문제를 대상으로 삼는다.

CEO,   Senior    Editors,   Junior   Editors,   Translators,   Localization

Specialists, Proofreaders로 구성된 역할 기반 다중 에이전트 조직을 구축하

였고 인간 평가자와 LLM 선호도 평가에서 전문 인간 번역과 GPT-4 기반의 단

일 LLM 번역보다 우수한 평가를 받았다. 이는 다중 에이전트 시스템이 문학




                                     6
번역과 같은 복잡한 작업뿐만 아니라 전문 용어 번역처럼 정확성이 요구되는

환경에서도 효과적일 수 있음을 시사한다.




제 2 절 RAG

 LLM의 성능이 비약적으로 발전하면서 다양한 자연어 처리 분야에서 높은 성

능을 보여주고 있으나 사전에 학습되지 않은 지식에 대해서 잘 처리하지 못하

는 한계점을 가지고 있다. 특히 의료, 기술, 법률과 같은 저자원 도메인에서

는 훈련 데이터에 도메인 지식이 충분하지 않아 전문 용어를 잘못 사용하거

나, 잘못된 개념을 학습하여 잘못된 정보를 생성하는 할루시네이션 현상이 발

생한다[6]. 번역 도메인에서는 용어의 정확한 번역이 중요한데 이와 같은 한

계점은 LLM을 번역 도메인에서 사용하는데 심각한 문제점으로 작용한다.

 이러한 한계점을 보완하기 위해서 RAG(Retrieval-Augmented Generation) 기

법이 사용된다[7]. RAG는 외부 지식을 검색하여 LLM의 입력 컨텍스트로 사용

함으로써 모델이 사전에 학습하지 않은 정보를 활용하여 신뢰도 높은 응답을

생성할 수 있게 하는 접근 방법이다.




                           7
                    <그림 1> RAG 시스템

 RAG 시스템은 Retrieval 단계와 Generation 단계를 포함한다. Retrieval 단

계에서는 사용자의 질의와 의미적으로 유사한 정보를 외부 데이터베이스에서

검색한다. 이 과정에서 주로 벡터 유사도 검색이 사용된다. 사용자의 입력을

벡터로 변환한 뒤 사전에 구축된 지식 베이스의 임베딩과 비교하여 높은 유사

도를 가지는 문서들을 선정한다. Retrieval 단계를 통해 얻어진 문서들은 LLM

의 입력 컨텍스트로 사용되기 때문에 사용자의 질의와 관련된 문서가 검색되

는 것이 중요하며 이 때문에 검색 품질이 전체 RAG 시스템의 성능에 큰 영향

을 미친다. 최근에는 벡터 유사도와 기타 BM25와 같은 키워드 검색 지표를 함




                           8
께 사용하는 하이브리드 기법[8], 검색된 문서들의 순위를 다시 조정하는 Re-

ranking 방법도 활발히 연구되고 있다[9]. Generation 단계에서는 검색된 문

서를 컨텍스트로 사용하여 LLM이 답변을 생성하도록 한다. 사용자의 질의와

검색된 정보를 기반으로 출력을 만들기 때문에 보다 정확하고 신뢰할 수 있는

답변을 얻을 수 있다.

 RAG를 번역 작업에 적용하는 연구들이 이루어지고 있으며 [10]에서는 번역

과정에서 미확인 용어를 식별한 뒤 해당 용어에 관한 지식을 RAG를 통해 검색

하여 활용하는 번역 프레임워크인 CRAT(Causality-Enhanced Reflective and

Retrieval-Augmented Translation with Large Language Models)을 제안하였다.

제안된 번역 프레임워크를 사용해 GPT-4o, Qwen-72B-Instruct 등 여러 LLM을

대상으로 한 실험에서 BLEU Score, COMET, CONSIS 지표가 일관되게 상승하는

결과를 보였다. 그러나 해당 연구는 영어와 중국어 간의 고자원 환경을 중심

으로 평가하였기 때문에 저자원 언어나 환경에서의 추가적 검증이 필요하다.

특히 한국어 저자원 도메인에서 RAG와 다중 에이전트를 결합하여 적용한 연구

는 부족한 실정이다.

 본 연구에서는 RAG의 장점을 저자원 번역 도메인에 적용하여 기존의 단일

LLM 기반의 모놀리식 시스템이 가지는 한계를 보완하고자 한다. 특히나 한국

어와 영문 병렬 데이터가 부족한 한국어 저자원 도메인에서는 LLM이 전문 용

어를 일관성 있게 번역하지 못하거나 부정확한 번역을 생성하는 문제가 반복



                                 9
적으로 발생한다. 이러한 문제점을 해결하기 위해서 한국어 monolingual 데이

터셋을 기반으로 RAG 지식 베이스를 구축하고 이를 번역 피드백 생성 과정에

활용함으로써 도메인 지식 부족으로 인한 번역 오류를 줄이고 전문 용어 번역

정확성을 높이도록 하였다.




제 3 절 다중 에이전트 시스템

 다중 에이전트 시스템(Multi-Agent System, MAS)은 여러 에이전트가 상호작

용하여 복잡한 문제를 해결하도록 하는 AI 시스템이다. 다중 에이전트는 개별

에이전트나 단일 시스템으로는 해결하기 어려운 복잡한 문제를 해결할 수 있

다. 다중 에이전트 시스템은 단순히 여러 개의 에이전트를 사용하는 것이 아

닌 각 에이전트가 각자의 역할을 가진 채 동일한 목표를 위해 상호 작용한다.

이는 실제 사람이 복잡한 문제를 해결하기 위해 각 분야의 전문가들이 상호작

용하는 모습과 유사하며 이러한 협력 구조는 작업을 분해하고 전문성을 바탕

으로 역할을 분배함으로써 전체 시스템의 효율성과 안정성을 높인다.




                        10
        <그림 2> 다중 에이전트 워크플로우 구성 (출처: [1] CC-BY-ND)

 다중 에이전트 시스템의 워크플로우는 그림 2와 같이 Prompt Chaining,

Routing, Parallelization, Orchestrator-Workers, Evaluator-Optimizer 등

다양한 방식으로 구성할 수 있다. 이 중에서 Parallelization은 의존성이 없

는 여러 작업을 동시에 처리함으로써 전체 처리 시간을 단축하는 구조이며,

Evaluator-Optimizer는 Optimizer 에이전트가 결과를 생성하고 Evaluator가

이를 평가하여 개선점을 제시하는 반복적인 구조이다. 본 연구의 시스템은

Parallelization 구조를 핵심적으로 사용하였다. 문장에 여러 개의 전문 용어

가 포함된 경우 각 용어에 대한 피드백 생성 및 검증을 독립적인 하위 작업으

로 분리하여 병렬로 수행함으로써 전체 처리 시간을 단축하였다.

                제 3 장 연구 방법

제 1 절 데이터 구성 및 전처리

 본 연구에서는 한국어 저자원 도메인 중 체스 도메인을 실험 대상으로 선택

하였다. 체스 도메인은 오프닝, 미들게임 등 명확하게 정의된 전문 용어를 가

지고 있어 번역 오류를 식별 및 평가하기 용이하다. 또한 LLM과 상용 번역기

의 경우 해당 도메인의 한국어 사전 학습 데이터가 충분하지 않아 오역이 발

생하는 전형적인 저자원 도메인 특성을 보인다.

 체스 도메인의 RAG 지식 베이스 구축을 위해 나무위키의 체스 관련 문서를

사용하였다. 나무위키는 인터넷상에서 여러 사람들이 편집할 수 있는 공개된

한국어 위키 웹 사이트로 다양한 도메인의 위키 문서가 존재한다. 체스와 관

련된 문서 5개를 사용하여 RAG 말뭉치를 구성하였고 사용한 문서는 표 1과 같

다.

제 2 절 RAG 지식 베이스 구성

 도메인 용어의 번역 정확도를 높이기 위해 도메인 지식이 담긴 말뭉치를 기

반으로 RAG 지식 베이스를 구성하였다. 구성 단계는 총 세 단계로 이루어져

있고 청크 생성, 한국어-영어 병렬 말뭉치 구축, 임베딩 및 벡터 데이터베이

스 구축 단계로 구성되어 있다.




           <그림 5> RAG 지식 베이스 구축 플로우




                      15
 청크 생성 단계에서는 사전에 전처리된 마크다운 형식의 도메인 말뭉치를

langchain[11]의 RecursiveCharacterTextSplitter를 사용하여 일정 크기의 청

크로 나누었다. RecursiveCharacterTextSplitter는 텍스트를 단락, 문장, 단

어 순서로 재귀적으로 나누어 의미적으로 관련 있는 텍스트 조각이 함께 유지

되도록 하며 텍스트를 분할한다. 이때 chunk size는 하나의 청크에 포함되는

최대 문자 수를 의미하며, overlap은 인접한 청크 간의 중복하여 포함하는 문

자의 개수이다. 청크의 크기가 지나치게 크면 불필요한 문맥이 포함되어 검색

효율이 떨어지고, 반대로 너무 작은 경우 문맥의 단위가 파편화되어 검색 품

질이 떨어질 수 있다. 이러한 점을 고려하여 본 연구에서는 chunk size는 500,

overlap은 75로 설정하였다.

 한국어-영어 병렬 말뭉치 구축 단계에서는 각 청크를 GPT-5 모델을 통해 영

어로 번역하였으며, 한국어 원문과 GPT-5 모델을 통해 생성된 영어 번역문을

하나로 묶어 하나의 청크에 한국어 원문과 영어 번역문이 포함된 병렬 말뭉치

형태로 저장하였다. 한국어 원문만을 사용하는 것이 아닌 한국어-영어 병렬

말뭉치 형태로 구성하는 방식은 중요한 이점을 제공한다. 먼저 본 연구는 영

어 입력을 한국어로 번역하는 경우를 중심으로 실험을 수행하기 때문에 사용

자의 입력이 영어로 주어지며 사용자의 입력에서 추출되는 도메인 용어 또한

영어이다. RAG 시스템의 Retrieval 단계에서 임베딩된 문서의 벡터와 RAG 쿼

리 벡터가 가까울수록 검색 성능이 향상되는데 한국어로만 이루어진 문서를



                             16
사용할 경우 RAG 쿼리와 RAG 지식 베이스 간의 언어의 차이로 인해 검색 성능

이 저하될 수 있다. 또한 병렬 구조로 이루어져 있기 때문에 하나의 번역 예

시로써 활용할 수 있는 장점을 제공한다. RAG를 통해 검색된 청크는 특정 전

문 용어의 번역 피드백을 생성하는데 사용하는데 한국어-영어 쌍으로 구성되

어 있는 청크를 통해 두 가지 언어 표현을 모두 참고하여 더 나은 품질의 피

드백을 생성할 수 있다. 저자원 도메인 특성상 RAG에 직접 사용할 병렬 말뭉

치가   부족한    환경이    많기   때문에    monolingual   말뭉치를   역번역(back-

translation)을 통해 합성 병렬 말뭉치를 만들어 활용하였다[12][13][14].

 임베딩 및 벡터 데이터베이스 구축 단계에서는 청크 단위로 구성된 한국어-

영어 병렬 말뭉치를 벡터화하여 DB에 적재하였다. 임베딩 모델은 OpenAI의

text-embedding-3-large를 OpenAI Embeddings API[15]를 통해 사용하였고 벡

터 데이터베이스로는 오픈소스 벡터 데이터베이스인 ChromaDB[16]를 사용하였

다. 유사도 측정에는 L2 거리(유클리드 거리)를 사용하였으며 검색 시 상위 5

개 문서를 반환하도록 설정하였다.




제 3 절 에이전트 설계

 한국어 저자원 도메인의 번역 품질을 향상시키기 위해서 다중 에이전트 기

반 번역 시스템을 설계하였다. 본 연구에서 제안하는 시스템은 한국어 저자원

도메인 번역 과정에서 발생하는 전문 용어의 번역 오류를 단계별로 개선하기



                              17
위해서 에이전트별 역할을 분리하여 구성하였고, 각 에이전트가 협력하여 번

역 품질을 개선하도록 하였다. 각 에이전트는 특정 기능을 수행하며 일부 단

계는 병렬적으로 수행함으로써 전체적인 처리 시간을 최적화하도록 하였다.

번역 플로우는 초벌 번역, 도메인 용어 추출, 피드백 생성, 수정 번역 단계로

구성되어 있고 이를 수행하기 위해서 초벌 번역 에이전트, 전문 용어 추출 에

이전트, 피드백 생성 에이전트, 수정 번역 에이전트로 총 4개의 에이전트로

구성하였다.

              <그림 6> 시스템 아키텍처

 초벌 번역 에이전트는 입력된 원문으로부터 초벌 번역을 생성하는 역할을

수행한다. 도메인 용어와 관련된 컨텍스트 정보 없이 LLM의 사전 학습된 지식

만으로 번역을 수행하여 초벌 번역을 생성한다.




                    19
 전문 용어 추출 에이전트는 입력된 원문으로부터 도메인과 관련된 전문 용

어를 추출하는 역할을 한다. 이후에 추출된 용어들이 RAG의 쿼리로 사용되기

때문에 전문 용어가 정확히 추출되는 것이 성능에 큰 영향을 주게 된다.

 피드백 생성 에이전트는 RAG를 통해 가져온 도메인 지식을 기반으로 특정

전문 용어가 어떻게 번역되어야 하는지 피드백을 생성한다. 이 과정에서 RAG

지식 내에서 용어를 선택하도록 프롬프트를 통해 강제하였다. RAG 지식 내에

주어진 용어를 사용한 문장이 없을 경우 RAG 지식이 아닌 사전 학습된 정보를

바탕으로 피드백을 생성하기 때문에 피드백의 품질이 낮아지게 된다. 따라서

RAG 지식 내에서 주어진 용어를 찾았는지 여부를 반환하도록 하여 RAG 지식에

서 찾지 못한 경우에 해당 피드백은 사용하지 않도록 하였다. 각 용어별로 피

드백이 생성되어야 하는데 이를 병렬적으로 수행되도록 하여 용어 수에 비례

하여 선형적으로 시간이 증가하지 않도록 설계하였다.

 수정 번역 에이전트는 원문과 초벌 번역 그리고 각 용어별 번역 피드백을

받아 번역을 수행한다. 한국어 저자원 도메인 특성상 LLM이 전문 용어가 잘못

학습된 경우가 존재하기 때문에 RAG 지식을 통해 생성된 올바른 피드백이 잘

못되었다고 판단하고 학습된 용어를 사용할 위험이 있다. 따라서 피드백을 통

해 추천된 용어를 최우선으로 사용하도록 프롬프트에 명시적으로 지시하였다.

각 에이전트의 구체적인 시스템 프롬프트와 입력 프롬프트는 부록 1과 부록 2

에 제시하였다.

제 5 절 성능 평가 방식

 번역 성능을 평가하기 위해 많이 사용되는 지표 중 통계 기반 지표로는

BLEU Score[17]가 있다. BLEU Score는 전통적인 자동 평가 지표로 기계 번역

과 레퍼런스 번역 간의 n-gram 일치도를 기반으로 번역의 성능을 측정하는 방

법이다. BLEU Score의 경우 문장 전체의 n-gram 일치도를 기반으로 평가하기

때문에 문장 내 일부 전문 용어가 잘못 번역되어도 나머지 부분이 정확하면

전체 점수에 미치는 영향이 제한적인 한계점이 존재한다[18].

 신경망 모델 기반의 지표로는 COMET[19]과 COMET-KIWI[20]가 존재한다.

COMET 모델은 원문, 기계 번역, 참조 번역을 입력으로 받아 점수를 계산하고

COMET-KIWI 지표는 원문과 기계 번역만 입력으로 받고 참조 번역을 필요로 하

지 않는 reference-free 지표이다. COMET과 COMET-KIWI 모델의 경우 일반적인

번역 용어 평가에는 효과적이나 저자원 도메인 용어 번역 평가에는 한계가 존

재한다. 신경망 기반의 모델의 특성상 학습 데이터에 대한 편향이 존재한다는

한계점이 존재한다[21]. 이러한 특성은 저자원 도메인에서 특히 문제가 되는

데 학습데이터에 도메인 용어와 관련된 예시가 부족하여 모델이 도메인 용어

에 대한 의미를 제대로 학습하지 못할 수 있다. 또한 COMET 모델 특성상 신경

망 기반으로 의미적 유사성을 평가하기 때문에 비슷한 의미의 잘못된 용어로

번역하였을 경우에도 점수가 높게 유지되는 경우가 발생한다.

로 검색된 컨텍스트의 신뢰도를 자동으로 평가하거나 신뢰도가 낮은 정보에

대해 웹검색을 통해 검증하는 방법 등이 연구될 수 있다.

 결론적으로 본 연구에서는 RAG와 다중 에이전트 시스템을 이용한 번역 시스

템이 한국어 저자원 도메인 전문 용어 번역에서 효과적일 수 있다는 가능성을

제시하였다. 제안된 시스템은 별도의 모델 파인 튜닝 없이도 번역 품질을 개

선할 수 있어 다양한 제한적인 환경에서도 실용적으로 활용될 수 있을 것으로

기대된다.

           하지 마세요.
