# 제 1 장. 서론

## 1.1 연구 배경 및 목적

신용평가는 금융기관이 차주(借主)의 부도 위험을 사전에 평가하여 대출 심사·금리 결정·리스크 관리에 활용하는 핵심 의사결정 절차이다. 신용카드, 주택담보대출, 개인신용대출 등 다양한 금융 상품의 발전과 함께 신용평가의 중요성은 지속적으로 증가하여 왔으며, 정확하고 신뢰할 수 있는 평가 모델의 개발은 금융기관의 건전성 확보와 소비자 보호 양 측면에서 핵심 과제로 부각되고 있다 [1].

전통적인 신용평가는 FICO 점수와 같은 점수 기반 모델을 활용하여 신용 이력, 부채 비율, 상환 내역 등의 변수를 선형 결합한 단순 가산 점수로 차주의 신용도를 산정하여 왔다 [2]. 이러한 점수 기반 시스템은 해석 용이성과 투명성 측면에서 장점을 가지지만, 비선형적 패턴이나 변수 간 복잡한 상호작용을 충분히 반영하지 못한다는 근본적 한계를 지닌다. 이러한 한계를 극복하기 위하여 최근 머신러닝 기반 신용평가 모델이 활발히 연구되어 왔으며, 특히 그래디언트 부스팅 트리 계열의 XGBoost [3], LightGBM 등은 정확도와 속도 양 측면에서 우수한 성능을 보이며 사실상의 표준 모델로 자리잡았다. 더 나아가 정형 데이터 특화 딥러닝 모델인 TabNet [4]은 어텐션 기반의 변수 선택 메커니즘을 통해 인스턴스 수준의 해석 가능성을 제공하여 신용평가 분야에서도 새로운 가능성을 제시하고 있다.

그러나 머신러닝 기반 신용평가 모델은 예측 성능이 향상될수록 모델 내부의 의사결정 과정이 복잡해져 사용자에게 결과를 설명하기 어려워지는 *블랙박스* 문제를 동반한다. 이는 단순히 학술적 문제에 그치지 않으며, 유럽연합 일반 데이터 보호 규정(GDPR) 제22조의 *자동화된 의사결정에 대한 설명 받을 권리*나 우리나라 금융위원회·금융감독원의 *금융 분야 AI 가이드라인*과 같은 규제 차원에서도 명시적 의무로 부과되고 있다 [5]. 따라서 신용평가 시스템은 높은 예측 정확도와 더불어 평가 결과를 차주에게 명확하게 설명할 수 있는 능력, 즉 *설명 가능성(explainability)* 을 동시에 충족해야 한다.

설명 가능한 인공지능(eXplainable AI, XAI) 분야에서는 SHAP(SHapley Additive exPlanations) [6]과 같은 기여도 기반 해석 기법이 사실상의 표준으로 자리잡았으며, TabNet의 어텐션 마스크와 같은 모델 내장형 해석 정보 또한 활발히 활용되고 있다. 그러나 이들 기법이 산출하는 결과는 본질적으로 변수별 수치 형태이므로, 일반 차주가 이해할 수 있는 자연어 설명으로 변환하기 위해서는 추가 단계가 필요하다. 최근 거대언어모델(Large Language Model, LLM)의 발전에 따라 ChatGPT, Claude, Gemini 등의 모델이 자연어 설명을 자동 생성할 수 있는 잠재력을 보여주고 있으며 [7], 검색 증강 생성(Retrieval-Augmented Generation, RAG) [8] 기법을 활용하여 모델 출력의 사실성을 일정 부분 보장할 수 있는 방법론이 제시되어 왔다.

그럼에도 불구하고, *정형 데이터 특화 모델 + XAI + LLM-RAG* 의 결합을 신용평가 도메인에 적용한 종합적 연구는 아직까지 충분히 이루어지지 않은 상태이다. 특히 (1) SHAP과 TabNet 어텐션이라는 두 종류의 인스턴스 수준 해석 정보를 어떻게 융합하여 LLM 컨텍스트로 구성할 것인지, (2) LLM이 생성한 설명의 환각(hallucination) 위험을 어떻게 정량적으로 평가하고 통제할 것인지, (3) 도출된 설명이 신용평가의 다양한 이해관계자(전문가·고객·규제기관) 관점에서 어떤 trade-off를 보이는지에 대한 명확한 답이 부재한 상황이다.

본 연구는 이러한 학술적 공백을 메우는 것을 목적으로 한다. 구체적으로, XGBoost의 SHAP local 기여도와 TabNet의 인스턴스 수준 어텐션 마스크를 *동의 기반(agreement-aware)* 으로 융합한 신규 컨텍스트를 설계하고, 이를 LLM-RAG 파이프라인에 입력하여 신용평가 결과 설명 리포트를 자동 생성한다. 또한 룰 기반·자연어 추론(NLI) 기반·교차 LLM 평가(Cross-Judge G-Eval) 기반·페르소나 기반 4-tier 평가 체계를 구축하여 생성된 설명의 사실성·충실성·민감 정보 노출·이해관계자별 적합성을 정량 측정한다. 본 연구는 단일 데이터셋 검증의 한계를 넘어, Kaggle Home Credit Default Risk와 UCI German Credit 두 개의 공개 데이터셋에서 동일 메커니즘을 검증함으로써 메커니즘의 일반화 가능성을 정량적으로 확인한다.

## 1.2 연구 동기 및 연구 질문

본 연구의 동기는 신용평가 도메인에서 기존 연구가 가지는 다음 다섯 가지 한계에서 출발한다.

첫째, **TabNet 어텐션의 활용 부재**이다. 기존 연구에서는 TabNet을 단독 예측 모델로 평가한 사례가 많으나, 어텐션 마스크가 제공하는 sparse한 변수 선택 정보를 다른 해석 기법(SHAP)과 결합하여 LLM 입력 컨텍스트로 활용한 사례는 거의 보이지 않는다. SHAP과 어텐션은 본질적으로 다른 해석 관점(전체 기여도 vs sparse 변수 선택)을 제공하므로, 두 정보의 동의 여부 자체가 의사결정의 신뢰도 신호로 활용될 수 있다.

둘째, **LLM 환각 차단의 차별성 검증 부재**이다. LLM 기반 자연어 설명 생성은 사실에 부합하지 않는 내용을 만들어내는 환각 현상을 본질적 위험으로 가지며, 신용평가와 같은 고위험 도메인에서는 이러한 환각이 즉각적인 신뢰 손상으로 이어진다. 단순한 hard constraint(예: "컨텍스트에 없는 변수는 생성 금지")만으로도 환각률을 충분히 낮출 수 있는데, 그렇다면 정교한 SHAP 기반 RAG의 차별성은 무엇인지에 대한 명확한 검증이 필요하다.

셋째, **공정성 보정의 신용평가 통합 부재**이다. 신용평가는 성별·연령 등 보호 속성에 대한 4/5 규칙(80% rule) 기반의 공정성 평가가 의무화되어 있다. 그러나 공정성 보정 기법(Reweighing 등)을 신용평가 모델에 통합 적용하면서 동시에 모델 성능 손실을 최소화한 종합 사례는 충분하지 않다.

넷째, **단일 데이터셋의 일반화 한계**이다. 대부분의 선행 연구는 단일 데이터셋(주로 Kaggle 또는 UCI 단일)에서만 평가가 이루어져 도출된 메커니즘이 데이터셋 특성에 의존하는지 일반 패턴인지 구별이 어렵다.

다섯째, **이해관계자별 평가 부재**이다. 자연어 설명은 같은 내용이라도 신용 전문가·일반 고객·규제기관 등 이해관계자에 따라 적합성이 달라질 수 있으나, 다수 페르소나 관점의 평가 프레임워크는 충분히 정립되어 있지 않다.

이러한 한계를 바탕으로, 본 연구는 다음 네 가지 연구 질문(Research Question)을 설정한다.

- **RQ1.** XGBoost의 SHAP local 기여도와 TabNet 어텐션 마스크를 동의 기반으로 융합한 컨텍스트가 LLM 자연어 설명의 *사실 기반 충실성(fact-grounded faithfulness)* 을 향상시키는가?
- **RQ2.** Hard constraint만으로 충분한 환각 차단이 가능한 상황에서, SHAP 기반 RAG와 본 연구의 fusion 컨텍스트는 어떠한 차별적 가치를 제공하는가?
- **RQ3.** Reweighing 기반 사전 처리(pre-processing) 공정성 보정이 신용평가 모델의 예측 성능 손실 없이 보호 속성 4/5 규칙을 통과시킬 수 있는가?
- **RQ4.** 본 연구의 fusion 메커니즘은 다른 데이터셋(UCI German Credit)에서도 일관된 패턴으로 작동하는가, 그리고 신용 전문가·고객·규제기관 페르소나 관점에서 어떤 trade-off가 관찰되는가?

## 1.3 본 논문의 기여

본 연구는 위 네 가지 연구 질문에 대응하여 다음과 같은 다섯 가지 기여를 제시한다.

- **C1. Agreement-aware Fusion Context의 신규 설계.** XGBoost의 SHAP local 값과 TabNet 어텐션 마스크를 인스턴스 수준에서 통합하여 *동의 그룹(agreed)*, *SHAP 단독(shap_only)*, *어텐션 단독(attention_only)* 세 그룹으로 분해한 JSON 컨텍스트를 신규 제안한다. 이 컨텍스트는 두 해석 모델의 합의 여부 자체를 LLM 프롬프트의 명시적 신호로 활용한다는 점에서 기존 연구와 차별화된다.

- **C2. 4-tier 다중 평가 프레임워크 구축.** 룰 기반 충실성(faithfulness)과 환각률(hallucination rate)을 1차 지표로 두고, mDeBERTa-v3 다국어 자연어 추론 모델 기반의 NLI 함의도(entailment rate)를 2차 의미적 지표로, 교차 LLM 평가(Cross-Judge G-Eval)에서 Anthropic Claude와 Google Gemini를 양방향 평가자로 사용한 4차원 척도(factual / completeness / sensitive / style)를 3차 LLM 평가 지표로, 마지막으로 신용 전문가·고객·규제기관 3개 페르소나 LLM 대리 평가를 4차 인간 친화 지표로 구성한 4-tier 평가 프레임워크를 구축한다.

- **C3. 4-mode 컨텍스트 비교를 통한 차별성 입증.** *no_shap*(원시 변수만), *generic_rag*(일반 도메인 지식 chunks 추가), *shaponly*(SHAP top-5만), *fusion*(본 연구의 동의 기반 융합) 네 가지 컨텍스트 모드를 동일한 인스턴스 30개에 적용하여 정량 비교한다. 그 결과 환각률 0%는 hard constraint만으로도 달성되지만, 사실 기반 의미적 충실성과 값 정확 인용은 fusion 모드에서만 일관되게 우월함을 입증한다.

- **C4. 일반화 검증.** 본 연구의 메커니즘을 Kaggle Home Credit Default Risk(약 30만 건, 214 특징) 외에 UCI German Credit(1,000건, 63 특징)에 동일 파이프라인으로 이식하여 검증한다. 두 데이터셋에서 SHAP × 어텐션의 Spearman 상관계수가 거의 동일하게 약한 양의 상관(ρ≈0.11)을 보이며, NLI 함의도 4-mode 단조 증가 패턴 또한 일관됨을 확인한다.

- **C5. 공정성 보정의 통합 적용.** Kamiran-Calders Reweighing [9]을 보호 속성 GENDER·AGE 두 가지에 대해 baseline 데이터셋과 보조 테이블 추가 데이터셋(aux) 양쪽에 적용하여, AUROC 손실 0.003 이하 수준에서 4가지 조합 모두 4/5 규칙(Disparate Impact ratio ≥ 0.8)을 통과시킴을 확인한다.

또한 본 연구는 모든 코드를 GitHub 공개 저장소(`Tim-Green0/tabnet-xai-rag-credit`)에 공개하여 재현 가능성을 확보한다.

## 1.4 논문 구성

본 논문은 총 5개의 장으로 구성되며, 각 장의 주요 내용은 다음과 같다.

**제2장 이론적 배경**에서는 신용평가 시스템의 일반 이론, 머신러닝·딥러닝 기반 신용 리스크 예측 연구의 동향, SHAP과 TabNet 어텐션 등 설명 가능한 인공지능 기법, 거대언어모델 기반 자연어 설명과 RAG의 원리, 신용평가 분야에서의 공정성 평가 및 보정 기법, 그리고 LLM 평가 방법론(G-Eval, NLI 기반 함의도 평가)을 차례로 다룬다.

**제3장 연구 방법론**에서는 본 연구의 데이터·시스템·평가 체계를 통합 기술한다. 먼저 3.1절에서 두 가지 공개 데이터셋(Kaggle Home Credit Default Risk와 UCI German Credit)의 특성, 탐색적 데이터 분석 결과, 결측값 처리·범주형 변수 인코딩·데이터 분할 등 전처리 정책을 다룬다. 이어 3.2절에서는 본 연구가 제안하는 시스템의 4단계 파이프라인 구조를 제시한 후, XGBoost와 TabNet 예측 모델 학습 과정, SHAP local과 TabNet 어텐션 마스크 추출 방법, *동의 기반 융합 컨텍스트* 의 설계 원리와 JSON 구조, LLM-RAG 자연어 설명 생성을 위한 프롬프트 설계와 hard constraint 정책, 그리고 Reweighing 기반 공정성 보정 기법을 구체적으로 설명한다. 마지막으로 3.3절에서는 본 연구의 4-tier 평가 체계, 즉 모델 성능 지표(AUROC, AUPRC, KS, F1), 룰 기반 충실성·환각률 측정 방법, mDeBERTa-NLI 함의도 평가, 교차 LLM G-Eval 4차원 척도, 3 페르소나 대리 평가, 그리고 공정성 평가 지표(Demographic Parity, Equal Opportunity, Disparate Impact)를 정의한다.

**제4장 분석 결과**에서는 본 연구의 모든 실험 결과를 통합 보고한다. 모델 성능 비교(5-fold CV), 신용평가 산업 벤치마크 대비 AUROC 0.76의 실무 수준 평가, SHAP × 어텐션 일관성 분석, 4-mode 자연어 설명 평가, 페르소나별 trade-off, 공정성 보정 결과, 그리고 UCI German Credit에서의 일반화 검증 결과를 포함한다.

**제5장 결론 및 시사점**에서는 본 연구가 도출한 핵심 발견과 한계(소표본, 정식 IRB 인간평가의 부재, hard constraint 의존성 등)를 *honest reporting* 의 관점에서 정리(5.1절)하고, audit·고객 응대 등 응용 시나리오별 모드 선택 가이드라인, 학술적·산업적 기여, 그리고 향후 연구 방향(5.2절)을 제시한다.
